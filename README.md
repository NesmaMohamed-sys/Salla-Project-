# Salla-Project-
مشروع لتحليل أداء مركز الاتصال في شركة سلة باستخدام Power BI وDAX. ركزت على مستوى الخدمة الشهري، معدل التخلي، ووقت الاستجابة، مع تقييم أداء الوكلاء وتحديد نقاط التحسين. أنشأت داشبورد تفاعلي يساعد فرق الدعم على اتخاذ قرارات أسرع وأذكى. المشروع يوضح كيف تتحول البيانات من أرقام إلى رؤى لتحسين تجربة العميل باستمرار.
